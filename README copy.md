# PDF 보고서 기능 추가본

첨부한 코드에 PDF 생성 함수와 회의 기록별 생성/다운로드 버튼만 추가했습니다.
기존 채팅, 음성, 이메일, 마감 달력, 요약 저장/검색 로직은 유지했습니다.

## GitHub에 올릴 파일
- app.py: 기존 파일 교체
- requirements.txt: 기존 의존성에 reportlab 추가 (첨부 코드에 필요한 전체 목록 포함)
- fonts/NanumGothic-Regular.ttf 및 fonts/OFL.txt: 폴더 그대로 추가

app.py 하나만 복사하면 폰트가 없어 PDF를 생성할 수 없습니다.

## 사용
1. 회의록 업로드 후 회의 전체 요약 요청
2. 회의 기록 탭에서 해당 회의 펼치기
3. PDF 보고서 만들기 클릭
4. PDF 보고서 다운로드 클릭

기존 저장된 회의 요약에도 사용할 수 있습니다.
추가 AI 호출 없이 저장된 요약 전문을 PDF로 변환합니다.
제목, 회의 날짜, 저장 시각, 항목별 본문, 쪽번호를 넣습니다.
Markdown 표가 있으면 PDF 표로 변환하며 일반 문장은 그대로 유지합니다.
요약에 없는 업무나 결정 사항을 추가하지 않습니다.
회의명·날짜·요약이 바뀌면 새 PDF를 생성해야 합니다.

## 검증
- 변경된 전체 Python 코드 구문 검사 완료
- 한글 폰트 포함 PDF 실제 생성 및 페이지 렌더링 확인
- 표 포함 1페이지 예시 및 5페이지 긴 요약 생성 확인
- 실제 Streamlit 배포 및 사용자 API 연동 실행은 이 환경에서 검증하지 않았습니다.
- sample_report.pdf는 형식 확인용 가상 예시이며 실제 회의 분석 결과가 아닙니다.

참고: 기존 코드의 summaries.json은 서버 로컬 파일이므로 영구 저장/다중 사용자 분리 방식은 기존과 같습니다.
